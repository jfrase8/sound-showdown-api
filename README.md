# Sound Showdown API — Board Game Backend

Sound Showdown API is a backend service for a custom board game featuring original rules and mechanics. The API models complex game entities, enforces gameplay rules, and provides a maintainable, object-oriented foundation for game logic and future expansions.

## Overview
This project focuses on backend system design and game logic rather than UI. It encapsulates core gameplay mechanics in a scalable codebase, ensuring correctness, testability, and long-term maintainability.

## Features
- Object-oriented architecture for board game logic  
- Modeled game entities, interactions, and rule enforcement  
- Clear separation of concerns between game state, actions, and rules  
- Automated tests validating core gameplay mechanics  

## Tech Stack
- **Language:** C#  
- **Framework:** .NET  
- **Architecture:** Object-Oriented Design  

## Key Highlights
- **Game Logic Architecture:** Engineered a clean, object-oriented backend architecture to represent players, game state, actions, and win conditions.  
- **Rule Enforcement:** Modeled complex interactions and constraints to ensure all gameplay rules are consistently enforced.  
- **Maintainability & Scalability:** Designed the system to support future mechanics and expansions without major refactoring.  
- **Automated Testing:** Implemented automated tests to validate gameplay logic and ensure correctness of core mechanics.
